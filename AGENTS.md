# Project instructions

- Keep commits concise and free of attribution or advertising. Update existing documentation instead of creating per-change summaries.
- Record explicit user decisions promptly in `docs/decision_log.md`, with an ISO 8601 timestamp including timezone offset. Preserve prior entries and append superseding decisions; do not log inferred preferences as user decisions.
- When finishing a branch, push and create a PR. Never merge unless every CI check is green; do not use bypass flags.

## GRREAT project memory

Start at `docs/grreat/README.md` and read its manifest-selected records. The active Execution record's **Now** section identifies the next action and verification state.

Plan by dependencies and acceptance criteria, without timelines. Keep Plan-mode writes deferred. Record meaningful work and evidence once in a linked journal, update Now, and assess the accepted milestone criteria in Analysis. Use project-scoped zvec-grep when semantic discovery is needed; do not create or rebuild an index without authorization.

End substantial work with validation and versioned direct-RPC sync when an authenticated destination is available. Missing credentials remain pending; preserve checkpoints and expose conflicts. Markdown stays authoritative. Never claim runtime, deployment or outcome evidence from source inspection alone.
